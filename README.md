# Sales Mini Dashboard Analysis

This project provides a comprehensive sales analysis for a major beverage company, visualizing key performance metrics across the United States. The goal is to identify seasonal trends, pinpoint geographical sales hotspots, and provide a clear overview of business performance. Using Microsoft Power BI, the dashboard transforms raw sales data into actionable insights.

# Mini - Project Overview

The interactive dashboard enables stakeholders to explore:

* Revenue, Units Sold, and Average Price
* Seasonal Trends across months
* Geographical Sales Hotspots by state
* Brand-Specific Performance (eg Coca-Cola, Sprite, Fanta)
* Filters and drill-down options allow both high-level overviews and detailed brand-level analysis.

# Workflow and Methodology:

1. Data Sourcing - Used a transactional sales dataset with revenue, units sold, price, date, and state details.

2. Data Cleaning & Preprocessing (Power Query) - Removed duplicates and handled missing values.Standardized data types for accurate reporting.mExtracted Month and Year for time-based trend analysis.

3. Data Modeling & Analysis - Built measures to calculate revenue, units sold, and average pricing. Created hierarchies to support drill-down analysis.

4. Data Visualization (Power BI) - Designed a clean and intuitive dashboard.


# Key Findings & Insights

* Strong Performance: $8.20M revenue from 16.45M units sold with an average unit price of $0.48.

* Seasonality: Sales peak in July–August (summer demand) and show a secondary spike in December (holiday season).

* Geographical Hotspots: Eastern and Southern U.S. drive the majority of sales, especially Florida, Texas, and Northeast states.

* Brand Insights: Interactive filters reveal brand-specific popularity by region and season.

# Conclusion
The Beverage Sales Dashboard enables data driven decision making by highlighting when and where sales are highest. These insights help optimize inventory, align marketing campaigns with seasonal demand, and prioritize high revenue regions to maximize growth.
